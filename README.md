# PKL - Project Magang Website (INC.85 ASIA - PREMIUM STORE) 🛒

Proyek ini adalah aplikasi web e-commerce **INC.85 ASIA - PREMIUM STORE** yang dikembangkan menggunakan Python (Flask), basis data SQLite (`toko.db`), dan antarmuka Tailwind CSS.

## 📁 Struktur Folder
toko_penjualan/
├── static/          # Menyimpan file unggahan (gambar produk, bukti transfer, logo)
├── templates/       # Menyimpan file HTML (index.html)
├── app.py           # Script utama backend Flask & routing API
└── toko.db          # Database SQLite

#Prasyarat (Requirements)
Sebelum menjalankan proyek ini, pastikan komputer Anda sudah terinstal:
  Python 3.x
  Package manager pip

#Cara Instalasi & Menjalankan Aplikasi
  1. Clone Repositori ini
  Buka Terminal / Command Prompt, lalu jalankan perintah:
  git clone [https://github.com/BayuKusuma10/PKL-Project-Magang-Website.git](https://github.com/BayuKusuma10/PKL-Project-Magang-Website.git)

  2.Masuk ke Folder Proyek
  Pindah ke folder tempat file app.py berada:
  cd "PKL-Project-Magang-Website/Project Magang Website/toko_penjualan"

  3.Instal Library Flask
  pip install flask

  4.Jalankan Aplikasi
  python app.py

  5.Akses di Browser
  Buka browser (Chrome/Edge/Firefox) dan buka alamat:
  http://127.0.0.1:5000
